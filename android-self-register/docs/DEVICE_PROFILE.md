# 基準端末プロファイル

実機確認日：2026-08-11

| 項目 | 確認値 |
|---|---|
| メーカー識別 | rockchip |
| 型番 | POCM-SM100 |
| Android | 12 |
| APIレベル | 32 |
| 物理解像度 | 1024 × 600 |
| 画面密度 | 120 dpi |
| 画面回転 | 自動回転有効 |

## アプリ調整方針

- POCM-SM100を店頭セルフレジの基準端末とする。
- アプリは横画面に固定する。
- 1024×600で会員証、利用先、支払方法の主要操作がスクロールなしで収まることを必須にする。
- メニュー一覧のみ縦スクロールを許可し、注文内容と会計ボタンは常時表示する。
- 主要ボタンは物理画面上で十分なタップ領域を確保する。
- Android 12で動作するため、`minSdk 28`の現在設定で対応可能。
- 自動回転は端末側で有効だが、Activityをランドスケープ固定して画面崩れを防止する。

無線デバッグの接続先、ポート、ペアリングコードはこの文書やGitHubへ保存しない。
